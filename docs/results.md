# 학습 실험 결과

C5와 C60은 각각 5개·60개 전각 실험을 구분하는 문서상 표기입니다. 원본 파일의 EXP 번호는 변경하지 않았습니다. epoch는 학습 반복 횟수이며 아래 표는 저장된 선택 모델 기준입니다.

## 60개 전각 동일 검증 비교
Combined 개발 검증 568장을 사용했습니다. 이전 522장 내부 시험과 직접 비교하지 않습니다.

|실험|선택 epoch|입력 크기|Top-1|Top-2|Top-3|
|---|---:|---:|---:|---:|---:|
| C60-E01 | 20 | 224 | 87.85% | 93.66% | 95.95% |
| C60-E02 | 4 | 224 | 88.91% | 95.07% | 96.83% |
| C60-E03 | 4 | 320 | 91.20% | 96.48% | 97.36% |
| C60-E04 | 2 | 320 | 88.73% | 94.37% | 96.83% |
| C60-E05 | 16 | 320 | 92.78% | 96.83% | 97.89% |

- C60-E01: 추가 학습 전 기준 모델.
- C60-E02: 사진 보강 학습. 클래스 가중 손실과 증강, BatchNorm 통계 고정 적용.
- C60-E03: 입력 크기를 320으로 변경.
- C60-E04: 추가 사진의 추출 비중을 25%로 설정.
- C60-E05: 전각별 학습 장수에 따라 사진 추출 빈도 조절. 현재 사용 모델.

보강 실험은 같은 기준 체크포인트에서 출발했습니다. 각 실행의 설정과 모델 선택 기준은 config.json에 있습니다. 원본의 internal/external 필드는 당시 선택 기준을 재현하기 위해 유지했습니다. 본문 성능은 Combined로 비교합니다.

## 소량 전각 샘플링 상한 비교
사진당 가중치는 min(√(150/n), c)입니다. n은 클래스별 학습 장수입니다. 이 식은 실험용 설계이며 최적해로 유도한 식은 아닙니다.

|상한 c|Top-1|Macro F1|Top-3|소량 전각 평균 재현율|
|---|---:|---:|---:|---:|
|1.5|92.96%|92.22%|97.01%|89.78%|
|2 현재 사용|92.78%|92.36%|97.89%|91.44%|
|3|92.78%|92.71%|97.71%|91.65%|

소량 전각은 학습 37장 이하 29개로 고정했습니다. 상한 2는 모든 지표에서 최고인 모델은 아닙니다. 현재 Top-3 제공과 웹 실행에는 상한 2 모델을 사용하고 있으며 비교 모델의 결과도 보존했습니다. 작은 차이의 재현성은 추가 확인이 필요합니다.

입력 해상도와 앙상블의 추가 비교는 evaluation의 해당 이름 폴더에 있습니다. 미채택 결과도 함께 보존합니다. 표의 정확도는 저장된 사진별 예측을 다시 집계해 확인했습니다.
