# 실행과 연동

## 웹 점검 페이지
1. 모델 파일을 web/models/README.md에 적힌 이름으로 별도 확보합니다.
2. web/browser에서 `npm ci`를 실행합니다.
3. 저장소 루트에서 `python -m http.server 8000 --bind 127.0.0.1`을 실행합니다.
4. 노트북에서 http://127.0.0.1:8000/web/mobile/index.html 에 접속합니다.
5. 모델 준비 후 사진을 선택하고 후보 및 실행 결과 JSON을 확인합니다.

모델 공유 URL은 아직 등록하지 않았습니다. 원본 페이지의 사용자 실행은 확인했지만 이관된 경로의 브라우저 실행은 별도 확인이 필요합니다. 휴대폰 검증에는 필요한 정적 파일만 HTTPS로 배포합니다. 저장소 전체를 외부에 공개하지 않습니다.

## 프론트 연결
class_index는 모델 출력 순서이며 card_id와 다릅니다. web/integration/class_mapping.json과 recognizer.mjs에서 후보를 카드 ID에 연결합니다. 점수는 Softmax 값이며 정답 확률을 보증하지 않습니다. 카드 ID는 원본 학습의 임시 building:번호가 아니라 현재 매핑 파일을 사용합니다. API 실제 연결 확인은 남아 있습니다.

## 학습과 분석 코드
experiments는 실험 당시 저장된 소스·설정·이력입니다. 실행에는 해당 데이터 매니페스트와 초기 가중치가 필요합니다. 원본 상대 경로 또는 개인 절대 경로가 남아 있으므로 자료를 확보한 후 조정해야 합니다. 이관만으로 재현이 완료된 것은 아닙니다.

optimization/scripts와 evaluation/scripts도 원래 개발 폴더의 모델·입력 텐서에 의존합니다. 지금은 방법 확인 및 재현 준비를 위한 연구 코드이며 범용 실행 CLI는 아닙니다. demo/matlab에는 시연 코드만 포함했고 모델과 예시 사진은 별도입니다.

현재 학습 환경 기록은 PyTorch 2.5.1 및 torchvision 0.20.1, 웹 런타임은 ONNX Runtime Web 1.30.0입니다. 모델·데이터를 Git에 포함하지 않는 것은 팀 협업 가이드에 따른 것입니다.
