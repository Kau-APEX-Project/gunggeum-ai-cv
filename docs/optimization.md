# 모델 경량화와 웹 실행

## 경량화 비교
FP16은 부동소수점 정밀도 축소, INT8은 정수 양자화입니다. 같은 개발 검증 568장을 평가했습니다.

|방식|파일 MB|Top-1|Top-2|Top-3|판단|
|---|---:|---:|---:|---:|---|
|FP32|16.33|92.78%|96.83%|97.89%|비교 기준|
|내부 연산 FP16|8.22|92.78%|96.83%|97.89%|CPU 정상, WebGPU 출력 오류|
|정적 INT8|4.87|65.67%|77.46%|82.57%|정확도 하락|
|가중치 INT8|4.40|91.37%|96.48%|97.71%|일부 정확도 하락|
|가중치 FP16|8.22|92.78%|96.83%|97.89%|현재 사용|

가중치 FP16은 저장 시 크기를 줄이고 실행 시 FP32로 복원합니다. 내부 계산까지 FP16으로 줄이는 방식과 다릅니다. 파일 용량은 약 절반으로 줄었지만 실행 메모리나 계산량이 절반이 된 것은 아닙니다. QAT 재학습은 수행하지 않았습니다.

## 웹 실행 검증
WebGPU와 WASM은 양자화 방법이 아니라 실행 방식입니다. WebGPU는 GPU, 이번 WASM 설정은 CPU를 사용합니다. 가중치 FP16 모델은 노트북 WebGPU 전체 검증에서도 위 Top-k 정확도를 유지했습니다. 별도 실행의 추론 중앙값은 FP32 25ms, 가중치 FP16 24.5ms였습니다. 이 차이로 속도 개선을 단정하지 않습니다.

사진 파일 12장을 브라우저에서 직접 처리했을 때 두 모델의 Top-3 순서는 모두 같았고 정답은 각각 11/12장이었습니다. 결과 일치율과 정확도를 구분합니다.

## 아이폰 점검
Cloudflare Quick Tunnel로 노트북 테스트 페이지를 임시 HTTPS 주소에 연결했습니다. 모델은 휴대폰으로 전달하고 사진 추론은 휴대폰에서 실행했습니다. 사진을 서버로 업로드하지 않았습니다.

|Safari 재측정|WebGPU|WASM|
|---|---:|---:|
|모델 다운로드|1.07초|1.05초|
|세션 생성|3.86초|4.24초|
|준비 전체|5.32초|5.68초|
|첫 사진 처리|121ms|118ms|
|반복 추론 중앙값|61ms|70ms|

3장씩 실행해 두 방식의 후보 순서가 같았습니다. 모바일 전체 정확도 평가가 아닙니다. 이전 Safari에서는 다운로드와 세션 생성의 합이 약 45.93초였습니다. 캐시·통신 조건이 기록되지 않아 첫 방문 45초, 재방문 5초라고 해석할 수 없습니다.

WebGPU 우선·실패 시 WASM 전환 방향으로 준비합니다. 최초 로딩 개선, 자동 전환 시험과 안드로이드 검증은 남아 있습니다.
