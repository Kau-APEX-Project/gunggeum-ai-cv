# 개발 과정

## 데이터 준비
공유받은 이미지와 라벨을 점검하고 손상된 파일을 대체했습니다. 전각별 명칭과 서비스 ID를 대조한 뒤 유사 사진을 그룹으로 묶어 분할했습니다. 같은 그룹은 학습·검증·시험에 걸쳐 나누지 않았습니다. 유사 그룹이 실제 촬영 세션과 완전히 같다는 뜻은 아닙니다.

## 5개 전각 시범 실험
향원정·경회루·근정전·교태전·광화문 471장을 기존 분할에서 추출했습니다. 학습 329장, 검증 70장, 시험 72장입니다. EfficientNet-B0의 분류층 학습 후 전체 미세조정을 비교했습니다. 최초 내부 시험은 72/72장이었으나 인터넷 사진 122장에서는 85.25%였습니다.

광화문 사진 보강, 밝기 증강, 근정전 사진 보강을 순서대로 비교했습니다. 후속 실험의 최고 결과는 같은 122장에서 87.70%였습니다. 이 사진들은 개선 과정에서 반복 확인했으므로 독립적인 최종 시험으로 취급하지 않습니다.

## 60개 전각 확대
기준 분할은 학습 2,402장, 검증 511장, 시험 522장입니다. 최초 모델의 내부 시험 정확도는 91.76%였습니다. 추가 사진을 확보한 후 학습 2,554장, Combined 개발 검증 568장으로 보강 실험을 진행했습니다.

사진 수 차이를 완화하기 위해 적은 클래스의 오류에 더 큰 비중을 주는 가중 손실과, 적은 클래스의 사진을 더 자주 뽑는 샘플링을 비교했습니다. 입력 해상도, 추가 사진 추출 비중, 샘플링 상한과 앙상블도 비교했습니다. 결과는 results.md에 정리했습니다.

## 현재 단계
현재 사용 모델의 Top-3 평가, MATLAB 사진 추론, ONNX 변환과 경량화, 웹·아이폰 실행을 확인했습니다. GPS 결합은 현재 범위에 포함하지 않습니다. 프론트의 후보 선택·카드 연결, 다른 휴대폰 확인, 현장 독립 시험이 남아 있습니다.
