# 현장 보강 학습

EXP005 epoch16을 시작점으로 현장 사진을 추가해 EfficientNet-B0 전체 가중치를 학습한 실험입니다. 선택 모델은 FP32 epoch12입니다. QAT는 수행하지 않았습니다. 원본 train.py에 QAT 분기가 남아 있지만 이 실험은 `--mode fp32`로만 실행했습니다.

## 데이터와 평가

| 구분 | 기존 자료 | 현장 자료 | 합계 |
|---|---:|---:|---:|
| 학습 | 2,554 | 505 | 3,059 |
| 개발 검증 | 568 | 150 | 718 |

현장 자료는 모델 예측 확인 후 제외·정리한 개발 자료입니다. 기존 시험용 사진 일부도 학습용으로 전환했으므로, 이번 결과는 독립 현장 시험 성능이 아닙니다. 촬영 그룹과 원본 해시가 학습·검증에 겹치지 않는지 학습 시작 시 검사합니다.

`comparison.csv`는 두 모델을 같은 검증 자료로 비교한 결과입니다. 568장과 718장 결과를 구분했습니다. Macro F1은 두 영역의 F1을 평균내지 않고 해당 평가 집합의 혼동행렬을 합쳐 다시 계산했습니다.

## 학습 방법

- 입력 320×320, batch 16, 최대 20 epoch, seed 20261109.
- AdamW: 본체 0.00001, 분류층 0.0001, weight decay 0.0001.
- BatchNorm 통계 고정, 클래스별 학습 장수의 제곱근에 반비례하는 손실 가중치 적용.
- 사진당 샘플링 가중치 min(sqrt(최대 클래스 장수 / 해당 클래스 장수), 2).
- 회전·이동·크기·밝기·대비·채도 증강.
- 기존 Combined 및 현장 검증의 Macro F1 평균으로 모델 선택, 동률이면 현장 Top-1 비교. 5회 연속 개선이 없으면 종료.

전체 설정은 `recorded_config.json`, epoch별 기록은 `history.csv`에 있습니다. 기록 파일은 실행 결과이며 train.py가 읽는 설정 파일은 아닙니다.

## 실행 준비

모델과 사진은 Git에 포함하지 않습니다. 담당자에게 `field_expand_gpu` 데이터 패키지를 받아 이 폴더에 아래 항목을 배치합니다. 팀 Drive/S3 공유 주소는 아직 등록하지 않았습니다. 확인된 파일 해시는 `assets.json`에 있습니다.

```text
field_training/
  train.py
  start.pt         # EXP005 epoch16 시작 가중치
  manifest.json    # 준비된 이미지 경로·라벨·분할 정보
  images/          # manifest와 일치하는 사전 처리 이미지
```

일반 원본 사진을 images에 복사하는 것으로 대체하면 안 됩니다. train.py는 패키지에서 미리 준비한 RGB 320×320 이미지를 사용하며, 읽을 때 다시 크기를 조절하지 않습니다.

CUDA 사용이 가능한 PyTorch 환경에서 다음을 실행합니다. 원래 실행 환경은 PyTorch 2.5.1+cu121입니다.

```bash
cd experiments/field_training
python -m pip install -r requirements.txt
python train.py --mode fp32 --device cuda --smoke
python train.py --mode fp32 --device cuda
```

`--smoke`는 한 배치의 순전파·역전파 점검입니다. 전체 학습 결과는 runs/fp32에 생성됩니다. 같은 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 기존 결과는 별도 보관한 뒤 새 실험을 실행합니다.
